# York Digital Journals (YDJ)

These pages provide detailed information about the [York Digital Journals (YDJ)](https://ydj.journals.yorku.ca) journal hosting service. It also provides information about practices and workflows in Open Journals Systems (OJS) relevant to YDJ's specific implementation of OJS and to YDJ editors' specific needs.
